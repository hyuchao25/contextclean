# ContextClean

ContextClean is a browser-based tool for cleaning noisy logs, stack traces, and debugging output before sending them to AI coding assistants.

Website:

https://www.contextclean.dev

## Features

- Clean stack traces and logs
- Remove repeated lines
- Reduce noisy debugging context
- Cleaning modes:
  - General
  - Node.js
  - Python
  - React / Next.js
  - Docker
  - CI / GitHub Actions
- Copy cleaned result
- Copy prompt for AI
- Download result as TXT
- Local browser-side processing
